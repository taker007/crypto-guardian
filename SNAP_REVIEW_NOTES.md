# Snap Review Notes — Crypto Guardian v1.1.1

## Purpose

Crypto Guardian is a MetaMask Snap that provides real-time risk signals for Ethereum token interactions and transactions. It analyzes tokens and contracts before users sign, helping them identify honeypots, rug pulls, and other high-risk patterns.

The Snap is advisory only — it does not block, modify, or execute any transactions.

## Architecture

```
User initiates transaction
        |
MetaMask triggers onTransaction handler
        |
Snap sends transaction data to public API
        |
API returns risk analysis (risk level, tradeability, signals)
        |
Snap displays results via snap_dialog
        |
User decides whether to proceed
```

## Public API Usage

All network requests are made to a single public endpoint:

- **Base URL**: `https://cryptoguardians.io`
- **Scan endpoint**: `POST /api/scan` — token risk analysis
- **Simulation endpoint**: `POST /api/tx/simulate` — transaction simulation

No local services, private IPs, or development endpoints are used.

### Runtime Private-IP Guard

The Snap includes a defensive runtime guard in `config.ts` that actively blocks any `localhost`, `127.0.0.1`, `192.168.x.x`, `10.x.x.x`, or non-HTTPS URLs. If any such URL is detected, it falls back to the production `https://cryptoguardians.io` endpoint. This guard exists as an additional safety measure and does not indicate any private endpoint usage.

## Permissions

| Permission | Purpose |
|---|---|
| `snap_dialog` | Display risk analysis results to the user |
| `endowment:rpc` | Handle RPC requests from dapps (analyzeToken, simulateTransaction) |
| `endowment:transaction-insight` | Intercept transactions before signing for risk analysis |
| `endowment:network-access` | Make HTTPS requests to the public CryptoGuardians API |

No additional permissions are requested. The Snap does not access wallet keys, sign transactions, or store any user data.

## Threat Intelligence Queries

The Snap performs two types of queries:

1. **Token Scan** (`POST /api/scan`): Sends a token contract address and chain ID. Receives risk level, tradeability status, risk flags, and intelligence observations.

2. **Transaction Simulation** (`POST /api/tx/simulate`): Sends transaction parameters (from, to, data, value, chainId). Receives severity assessment, confidence score, and recommendation.

Both queries are read-only and do not modify any on-chain state.

## Non-Custodial Guarantee

- The Snap never accesses private keys or seed phrases
- The Snap never signs or submits transactions
- The Snap never moves, transfers, or approves any assets
- All analysis is informational and advisory only
